Windows 麦克风 / 手机麦克风?

Windows 本机: 在 Windows 浏览器打开 http://localhost:5000 或 http://127.0.0.1:5000, 浏览器会直接使用 Windows 麦克风, 不需要 HTTPS. 不要使用 WSL 的 172.x IP.

局域网手机: 浏览器要求 HTTPS, 需生成开发证书并用 HTTPS 入口访问. 详见 docs/https-lan-microphone.md.
